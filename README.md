## 📥 Download

Get the **latest numbered fork release**: `v5.1.2-fork.7` on the [Releases](releases) page.

- **Android:** use `Spotube-5.1.2-fork.7-android-arm64-v8a.apk` for most phones; use `universal` only if you don’t know your ABI.
- **Linux:** use `spotube-linux-5.1.2-fork.7-x86_64.tar.xz`, or run `bash scripts/install-local.sh` from a checkout.

## ✨ Features

- Spotify metadata with real Liked Songs support
- Search, albums, artists, playlists, likes, and playlist editing
- Reliable playback and stream recovery
- Faster startup and smoother long-session playback
- Resumable downloads with duplicate skips
- Lyrics with faster, smoother loading
- Bundled Spotify metadata plugin
- Custom theme support, pinned playlists and radio stations, dockable player, and optional VPN routing
